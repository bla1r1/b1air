# Debian 13 (trixie) and newer, Ubuntu 25.04 and newer, and their derivatives.
# Format: see lib/distro.sh. `?name` = optional.
#
# Quickshell is not packaged here; install.sh builds it from source with the
# dependencies in packages/quickshell-build/debian.txt. swayFX is not packaged
# either: install.sh builds it with its own wlroots (tools/build-swayfx.sh,
# dependencies in packages/swayfx-build/debian.txt). Plain sway below is the
# fallback should that build fail.
