# b1air Symbols

`b1air-symbols.ttf` is the desktop's icon font, built by `tools/build-symbols.py`
from JetBrainsMono Nerd Font Mono (SIL OFL 1.1, the icon sets it bundles under
their own licences) with its icons redrawn from [Lucide](https://lucide.dev)
(ISC, `LICENSE-lucide.txt`). Rebuild it after using a new icon codepoint in the
source; the script prints which ones it could not match.
